# Fudan SafeTest 2026

复旦大学实验室安全课程阅读与考试辅助 Chrome 扩展，无需安装 Python、uv、Selenium 或 ChromeDriver。

扩展提供两个独立功能：

- **课程阅读**：在当前课程列表页依次打开未学习课程，按网站真实时间等待，到 `00 分 00 秒` 后滚动到底部并点击“阅读完成”。
- **安全考试**：进入考试并根据本地题库选择答案。

> 扩展不会查找或点击提交按钮。答题完成后，请核对答案并手动提交。

## 最短使用流程

1. 下载仓库并加载为 Chrome 未打包扩展。
2. 自行登录实验室安全平台，打开“考前学习资料”第一页。
3. 点击扩展中的 **自动完成课程阅读**，等待本页全部完成。
4. 手动翻到第二页，再点击一次 **自动完成课程阅读**。
5. 自行打开安全考试页面，点击 **打开并自动答题**。
6. 自动答题完成后核对答案，并手动提交试卷。

> 课程列表的第一页和第二页需要分别启动一次。扩展不会自动翻页，也不会自动提交试卷。

## 一、下载仓库

在 GitHub 仓库页面点击 **Code → Download ZIP**，下载完成后解压。

也可以使用 Git：

```bash
git clone git@github.com:Recqvq/Fudan_SafeTest2026.git
```

## 二、安装 Chrome 扩展

1. 在 Chrome 地址栏输入 `chrome://extensions/` 并打开。
2. 开启页面右上角的 **开发者模式**。
3. 点击页面左上角的 **加载未打包的扩展程序**。
4. 选择下载并解压后的仓库根目录，即直接包含 `manifest.json` 的文件夹。
5. 安装成功后，点击 Chrome 工具栏的拼图图标，将 **Fudan SafeTest** 固定到工具栏。

正确的文件夹结构如下：

```text
Fudan_SafeTest2026/
├── manifest.json
├── README.md
├── asset/
│   └── questions.json
└── extension/
    ├── content.js
    ├── popup.html
    └── popup.js
```

## 三、完成课程阅读

1. 自行登录实验室安全平台。
2. 打开“考前学习资料”的课程列表第一页。
3. 确认地址属于以下课程区域：

   ```text
   https://lsem.fudan.edu.cn/fd_aqks_new/examProgress/examOnline/...
   ```

4. 点击 Chrome 工具栏中的 **Fudan SafeTest**。
5. 点击 **自动完成课程阅读**。
6. 扩展会在当前页依次处理课程：
   - 只选择“未学习 / 未完成 / 未阅读 / 学习中”的课程；
   - 按网站显示的真实剩余时间等待；
   - 到 `00 分 00 秒` 后滚动到页面底部；
   - 点击“阅读完成”，然后继续本页下一门课程。
7. 出现绿色“课程阅读已全部完成”提示后，手动翻到第二页。
8. 在第二页再次点击 **自动完成课程阅读**。

需要中途停止时，再次打开扩展并点击 **停止课程自动阅读**。

> 扩展不会刷新或跳转当前课程页，不会修改倒计时、调用隐藏接口或伪造课程进度。无法可靠识别下一门课程时会停止并显示红色提示。

## 四、开始自动答题

1. 完成两页课程阅读后，自行打开安全考试页面。
2. 点击 Chrome 工具栏中的 **Fudan SafeTest**。
3. 点击 **打开并自动答题**。
4. 程序会识别安全考试、进入“实验室安全在线校级卷”并根据本地题库选择答案；未匹配的题会保持空白并自动跳到下一题。
5. 网页右上角会显示当前进度。
6. 出现绿色“答题完成”提示后，核对答案并手动提交试卷。

> 自动答题和课程阅读是两个独立功能。开始考试前，建议确认两页课程均已完成。

## 五、安全与隐私

- 扩展仅申请访问 `lsem.fudan.edu.cn`。
- 账号和密码由复旦登录页面处理，扩展不会读取或保存登录信息。
- 题库保存在本地 `asset/questions.json`，不会上传答题内容。
- 考试自动运行请求在十分钟后失效。
- 课程阅读任务最长保留 24 小时，刷新或同站跳转后可以继续。
- 课程功能只在网站显示剩余时间为 `00 分 00 秒` 后点击“阅读完成”。
- 题目匹配度低于 90% 或选项不完整时，该题会保持空白并继续下一题；最终提示会显示跳过数量。
- 答案选项通过网站实际使用的 iCheck 控件选择，并在翻页前确认选中状态。
- 自动答题代码中没有提交或交卷功能。

## 六、常见问题

### GitHub 更新后，Chrome 中的扩展会自动更新吗

不会。未打包扩展不会从 GitHub 自动更新。更新本地文件后，需要打开 `chrome://extensions/`，找到 **Fudan SafeTest** 并点击刷新图标。刷新后可在扩展卡片中确认版本号。

### 扩展会自动从第一页翻到第二页吗

不会。请等待第一页出现绿色完成提示，再手动翻到第二页并重新点击 **自动完成课程阅读**。

### 点击扩展后页面一直加载

先直接访问 `https://lsem.fudan.edu.cn/`，确认当前网络能够打开复旦实验室安全考试网站。网站本身无法访问时，扩展也无法继续。

### Chrome 提示无法加载扩展

确认选择的是直接包含 `manifest.json` 的仓库根目录，而不是 `extension` 子目录或 ZIP 压缩包。

### 网页右上角出现红色提示

不要反复点击扩展按钮。记录红色提示内容，再根据提示检查当前页面、课程状态或题库。

### 课程阅读提示“没有识别到下一门”

确认当前处于课程列表页面，而且列表中确实还有“未完成 / 未学习 / 学习中”的课程。扩展找不到明确的未完成课程入口时会安全停止。

### 在第二页启动后跳转到旧版 UIS 公告

请先确认 Chrome 扩展版本不低于 `2026.8.32`。新版会把脚本直接注入当前课程页，不刷新、不导航，并排除外部认证链接。如果当前不是课程列表或阅读页面，扩展只会提示切换页面，不会自动跳转。
